# AgentVille 가상 오피스 UI — 디자인 위임 브리프

## 1. 이전 담당(Claude)의 한계

| 항목 | 한계 |
|---|---|
| 그림 생성 | 이미지 생성 능력이 없음. 모든 그림을 코드(canvas 도형, 문자열 픽셀 맵)로 찍어야 함 |
| 픽셀 아트 품질 | 캐릭터 1종 틀에 색만 교체. 가구는 등각 상자 수준. 질감, 그림자, 조명 표현이 약함 |
| 해상도 | 400×252 논리 캔버스를 확대해서 디테일과 소품 밀도가 낮음 |
| 애니메이션 | 상태별 동작(타이핑, 손 흔들기, 졸기, 이동)이 없음 |
| 미적 판단 | 렌더링 결과를 스크린샷으로만 확인 가능. 다크 캔버스, 파스텔 미니룸, 귀여운 버전 모두 반려됨 |
| 에셋 조달 | 외부 타일셋을 받아 쓰지 않았음(아트 소스 A/B 미결정). 결과 수준이 참고 목업에 못 미침 |

## 2. 목표 수준

- 참고 목업 3장(픽셀 아트 가상 오피스 건물, My Room 화면, Codex 초기안) 수준의 완성도
- 등각(isometric) 픽셀 아트 사무실이 화면 중심, 대시보드 요소는 보조

## 3. 화면 구성

- 왼쪽 메뉴: 가상 오피스, 대시보드, 사원, 프로젝트, 타임라인, 지점, 설정
- 상단: 검색, 상태별 인원 필터(전체 · 작업 · 생각 · 대기 · 유휴 · 오류), 지점 선택
- 중앙: 선택한 지점(Branch)의 사무실 층 전경
- 오른쪽: 출근한 사원 목록, 최근 이벤트
- 하단: 지점별 연결 상태(heartbeat, 연락 끊김)

## 4. 도메인 규칙 (반드시 유지)

### 공간
- Host = 지점(Branch). HQ는 지점 중 하나의 역할
- Project(저장소 1개) = 방(Room) 1개
- 저장소 밖에서 일하는 에이전트 = 공용 사무실
- 지점마다 휴게실(Fika), 양호실(오류) 1개씩
- 집중실(Focus Room) 없음. 회의실은 추후

### 사원
- 사원(Employee) = (project, host, provider, seat)
- 서브에이전트 = Contractor. 상위 사원 옆, 안전모 착용
- 다른 지점에서 원격으로 같은 프로젝트에 참여한 사원은 지점 태그 표시(예: "Office")
- Provider는 로고 금지. 이니셜 배지 사용(CL = Claude, CX = Codex)

### 상태 → 그림

| 상태 | 표현 |
|---|---|
| working | 자리에서 타이핑, 화면 켜짐 |
| thinking | 자리에서 생각 중 |
| waiting (승인/입력 대기) | 손 흔들기 |
| idle 0–5분 | 자리에 앉아 있음 |
| idle 5–30분 | 휴대폰 보기 |
| idle 30–60분 | 졸기 |
| idle 60분 이상 | 휴게실로 이동(Fika) |
| error | 양호실 |
| limited (사용량 한도) | 컴퓨터 꺼짐, 시계 보기 |
| unknown | 판정 불가 표시 |

### 출근 상태
- on_duty(출근) / off_duty(퇴근) / on_leave(휴가, 7일 경과)

### Condition (모델 + 설정)
- extra-coffee: 커피 마시며 작업
- study-mode: 열공 모드
- lazy: 느긋함

## 5. 데이터 노출 금지

말풍선, 목록, 타임라인 어디에도 아래 항목을 표시하지 않음.

- 명령어, 도구 인자, 프롬프트, 작업 설명
- 원격 없는 저장소의 경로
- 계정 상세(별칭만 허용)

말풍선 허용 범위: 이름, provider 배지, 상태, 도구 이름 또는 경과 시간.

## 6. 기술 조건

- 정적 파일: `packages/agentville/hq/web/` (index.html, app.css, app.js). 빌드 도구 없음
- 데이터: `GET /api/v1/state`, `/branches`, `/agents`, `/stats`, 실시간 `WS /ws/v1/live`
- 에셋은 공개 저장소에 들어감. 라이선스가 재배포를 허용해야 함(CC0 또는 동등). 브랜드 에셋 금지
- 실제 로그 내용을 목업 데이터로 쓰지 않음. 합성 데이터만 사용
